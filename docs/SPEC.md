# すくすくワード 仕様書 (v0.6)

ひらがな・カタカナ学習アプリ。アプリ名は「すくすくワード」、ホーム画面に追加したときの表示名は「すくワー」。

## 1. 概要
- 対象ユーザー: 3歳児（個人・家族利用）
- 目的: ひらがな・カタカナの文字に親しみ、「なぞり書き」と「単語イメージ」を通じて文字を覚える
- 利用シーン: スマートフォン/タブレットを縦持ちで、保護者と一緒に、または一人で操作
- 公開範囲: 個人利用。Cloudflare Pages にデプロイして遊ぶ

## 2. スコープ (v1)

### 対応する文字
- ひらがな
  - 清音（あ〜ん、46文字）
  - 濁音（が・ざ・だ・ば行、20文字）
  - 半濁音（ぱ行、5文字）
  - 拗音（きゃ・しゃ・ちゃ・にゃ・ひゃ・みゃ・りゃ・ぎゃ・じゃ・びゃ・ぴゃ 各行、33文字）
- カタカナ
  - 清音・濁音・半濁音・拗音（ひらがなと同構成、104文字）

### 含むもの
- モード1: なぞる（なぞり書き。1文字 / ぎょうごと）
- モード2: カード（たんごカード。1文字 / ぎょうごと）
- モード3: かこう（えを みて かこう。ランダムな絵の単語を1文字ずつなぞる）
- モード4: ならべる（絵を見て、ばらばらの文字を順番に選ぶ。ダミーあり）
- 文字選択画面（ひらがな/カタカナ切り替え、清音・濁音・半濁音・拗音のグループ切り替え、ぎょう指定）
- 簡単な進捗・ごほうび機能（スター/スタンプを集める）
- 応援マスコットキャラクター（既存のキャラクターを使用）
- モバイル縦画面専用レイアウト（横画面・PCは非対応でよい）

### 含まないもの (v1)
- 音声読み上げ・発音機能
- ログイン/ユーザー管理・複数プロファイル
- 厳密な筆順判定（書き順の正確さを厳しく採点する機能）

## 3. 画面構成

0. **あんないキャラ えらび画面**（初回起動時に表示。ホームの「かえる」からも開ける）
   - 4人から1人をタップすると、そのキャラがあいさつする（自動では移動しない）
   - 「かいし」ボタンでホームへ。選んだキャラが全画面で案内役になる（`localStorage` に保存）
1. **ホーム画面**
   - タイトル + スター数、選んだキャラ（上半身）と吹き出し
   - モードボタン 2×2:「なぞる」「カード」「かこう」「ならべる」
   - 下段:「かえる」（キャラ変更）/ バージョン /「さいしんに する」（3.1）
2. **文字えらび画面**（なぞる・カード共通）
   - ひらがな / カタカナ 切り替え、グループタブ（あいうえお・てんてん・まる・ちいさい ゃゅょ）
   - 文字表を1画面に収めて表示（清音は わ・を・ん を1行にまとめて10行）
   - 文字タップ → その文字から開始。行の頭の ▶ → **その ぎょうだけ** を順番に進める
3. **なぞる画面**
   - 大きく薄いガイド文字（教科書体ふう）を指でなぞる（Canvas）
   - 文字が出るたびに **かきじゅん** をアニメーション（1画ずつ線がのび、書きはじめに番号）。なぞりはじめると消え、右上「かきじゅん」で再生
   - ボタン:「まえ」（ひとつ前の文字）/「けす」/「できた」
   - 「できた」→ キャラがほめる＋スター → ボタンが「つぎ」に変わる（ぎょう指定の最後は「おわり」）
   - 採点はしない（なぞったかどうかだけ見る）
4. **カード画面**
   - 表（文字）→ タップでめくると裏（絵＋単語。その文字をハイライト）
   - カタカナのときは単語の下に小さく ひらがなの よみ
   - 単語が無い文字（5章）は、めくるとキャラのリアクションのみ
   - 「まえ」「つぎ」で送る（ぎょう指定時は その ぎょう内）
5. **かこう画面**（えを みて かこう）
   - ランダムな絵と単語の文字を表示し、1文字ずつ薄い見本（かきじゅんつき）をなぞる（拗音「きゃ」等は1マス）
   - ボタン:「まえ」/「けす」/「できた」。「できた」→ ほめる → ボタンが「つぎの もじ」に変わる
   - **最後の文字のあとだけ**「つぎの え」になり、スター獲得（途中で別の単語へ飛ばない）
   - ひらがな / カタカナ 切り替えあり
6. **ならべる画面**
   - 絵と空の枠、ばらばらの文字タイル。正しい順にタップして枠を埋める
   - 間違えるとタイルが揺れてキャラが声かけ（減点なし）
   - レベル（星1〜3）: 1=ダミーなし / 2=ランダムなダミー2枚 / 3=形の似た文字を含むダミー3枚（`src/data/lookalike.ts`）

### 3.0 画面の共通ルール
- **スクロールしない**: 全画面を端末の高さに固定し、どの画面も1ページに収める（iPhone SE〜Pro Max 相当で確認）
- **文字選択・長押しメニュー・ダブルタップ拡大・ピンチ拡大をさせない**
- **セーフエリア**: 上下左右に `env(safe-area-inset-*)` ＋ 余白を取り、ノッチ・ホームバー付近にボタンを置かない
- **機種依存の絵文字は使わない**: アイコンは Lucide（SVG）、単語の絵は Fluent Emoji（SVG 同梱）
- **フォント**: セリフ・ボタンなどは丸ゴシック（M PLUS Rounded 1c）。**あそぶ文字**（文字表・なぞりのガイド・カード・かこう・ならべる の文字）は教科書体ふうの **Klee One** で、とめ・はね・はらい が分かるようにする（かなだけに絞った woff2 を `public/fonts/` に同梱）
- **セリフ（吹き出し）**
  - 自動では消えない・切り替わらない。**タップで次のセリフへ**（続きがあるときは右下に ＞ を表示）
  - 変な位置で改行しない: スペース・句読点で区切った「まとまり」の途中では改行しない
  - 最大2行。入らなければ文字を小さくして収める（`src/lib/fit.ts`）
  - セリフは区切りたい位置に半角スペースを入れて書く

### 3.1 最新版への更新ボタン
- ホーム画面に追加（スタンドアロン起動）するとブラウザのリロード操作ができないため、アプリ内に更新ボタンを置く
- ビルドごとに `version.json`（ビルド日時ベースのバージョン）を出力し、ボタン押下時に `cache: no-store` で取得して現在のバージョンと比較
  - 新しい版がある: Service Worker 登録解除・Cache Storage 削除のうえ、キャッシュ回避クエリ付きでリロード
  - 同じ版: マスコットが「もう さいしんだよ！」と話す
  - 取得失敗: 「いまは つながらないみたい」と話す
- Cloudflare Pages の `_headers` で `index.html` / `version.json` はキャッシュさせず、ハッシュ付きアセットのみ長期キャッシュ
- ホーム下部に小さくバージョンを表示（保護者が確認する用）

### 3.2 表記ルール（ふりがな）
- ユーザーは **ひらがなしか読めない** 前提とする。UI の文言は漢字を使わず、ひらがな（＋必要なカタカナ）で書く
- UI に出るカタカナには **原則ひらがなのふりがな（`<ruby>`）を付ける**（例: たんご<ruby>カード<rt>かーど</rt></ruby>、マスコットのセリフ中のカタカナ）
- ただし **カタカナ学習の場面では、学習対象の文字そのものにはふりがなを付けない**（文字表のグリッド、なぞり書きのガイド文字、たんごカードの表面）
  - 読み方が分からないと困る場面にだけ、必要に応じて控えめに読みを出す（例: なぞり書き画面の「よみ: か」）
- 実装は `src/lib/furigana.ts` の `withFurigana()` を使い、カタカナの連なりを自動で ruby 化する

## 4. なぞり書きの採点・かきじゅん
- 採点はしない（3歳児向けに、なぞったら「できた」で進めるシンプルな形にする）
- かきじゅんは KanjiVG の線データ（`public/data/strokes.json`、ひらがな・カタカナ・ー）を使い、SVG でガイド文字に重ねてアニメーションする
  - フォント（Klee One）と KanjiVG の形のずれは `src/components/board.ts` の補正値（`KVG`）で合わせている

## 5. データモデル（文字ごと）
単語データは `src/data/words.ts`。キーは ひらがな（拗音は2文字）、単語は ひらがな で持ち、カタカナモードでは自動変換する。
- その文字で始まる単語が無い場合は、**文字を一部に含む単語でよい**（ん → りぼん、ぐ → えのぐ、しゅ → はくしゅ）
- 「を」は例外で **みじかい文**（ほんを よむ）
- ちょうどいい単語が無い文字（ぢ・みょ・りゃ・びゃ・ぴゃ）は `null` とし、カードではキャラのリアクションのみ
- 音まね（ぴょんぴょん 等）や抽象的なもの（ひゃく 等）はカードのみで使い、かこう / ならべる の出題（`quiz: false`）からは外す

以下は元の想定項目:
- `char`: 表示文字（ひらがな/カタカナ）
- `group`: 清音 / 濁音 / 半濁音 / 拗音
- `romaji`: ローマ字（内部管理用、UIには出さない）
- `word`: 対応する単語（同じ文字種の表記）
- `image`: 単語イメージ（イラスト。将来差し替え可能な構造にする）
- 単語が存在しない文字（「を/ん」「ヲ/ン」等）は、たんごカードでは専用演出（マスコットのリアクションのみ）にする

  | anna | あんな | キュアアンサー | まっすぐで元気。くちぐせ「はなまる！」 |
  | mikuru | みくる | キュアミスティック | まじめな頑張り屋。です・ます調 |

- セリフは場面ごと（あいさつ / ホーム / ほめる / なぞってない / カード / 更新結果）にキャラ別で定義。ひらがな・カタカナのみで書く
- アプリアイコン: 正方形の `public/icon-512.png` / `icon-192.png` / `apple-touch-icon.png`（180px）/ `favicon.png`。現在はあんなの顔を切り抜いて作成

## 7. 技術構成
- Vite + TypeScript（vanilla、フレームワークなし。軽量重視）
- Canvas 2D API でなぞり書きを実装
- CSSアニメーションでマスコット演出
- 状態保存: `localStorage`（進捗・スター数。バックエンド無し）
- ビルド成果物を Cloudflare Pages にデプロイ（ビルドコマンド: `npm run build`、出力ディレクトリ: `dist`）
- GitHub リポジトリと Cloudflare Pages を連携し、`push` で自動デプロイ

## 8. デザイン方針
- 縦画面（375px前後基準）、3歳児の指でも押しやすい大きめのタップ領域
- 明るく親しみやすい配色（パステル + ビビッドアクセント）
- 丸みのある読みやすい書体（例: Google Fonts の "M PLUS Rounded 1c" 等）
